### [Decisions API is in public beta](https://news.ycombinator.com/item?id=49984025)

- **HN engagement:** 302 points, 148 comments
- **Primary topic:** OpenAI Decisions API public beta: structured predicate/choice/score questions with probability outputs
- **Evidence basis:** source-and-discussion
- **External page:** success
- **Source:** https://developers.openai.com/api/docs/guides/decisions

The API offers a purpose-built, input-token-only pricing endpoint for classification and routing tasks that previously required prompt engineering around chat completions or structured outputs. Competitive alternatives like Jev already exist at lower cost, so developers must evaluate whether OpenAI's ecosystem integration justifies any latency or price premium.

**Linked source:** The OpenAI Decisions API accepts an input and an array of typed questions (predicate, choice, or score) and returns probability distributions rather than free-text answers; the only currently available model is gpt-6-luna, priced at $0.10 per 1M input tokens with no output-token charges, and the API supports Zero Data Retention and HIPAA use for eligible customers.

**HN discussion:** Commenters largely frame the Decisions API as a reactive move against cheaper structured-decision competitors such as Jev and Mercury Decide, with one commenter running preliminary evals reporting that it is slower than Jev and shows lower confidence on ambiguous tasks. One commenter raises a broader concern that making probabilities visible could erode user trust in decisions that were previously presented without uncertainty estimates.

### [Strands Decider 2B: a small, open-source, decision model](https://news.ycombinator.com/item?id=49987076)

- **HN engagement:** 180 points, 45 comments
- **Primary topic:** Strands Decider 2B: a small open-source decision model for low-latency agent pipelines
- **Evidence basis:** source-and-discussion
- **External page:** success
- **Source:** https://strandsagents.com/blog/introducing-strands-decider/

A sub-2B model purpose-built for binary decisions can sit in an agent's tool-call intervention path at negligible cost, replacing expensive full LLM calls for structured gating logic. The open-source release with weights on Hugging Face and code on GitHub makes it directly deployable without a proprietary API.

**Linked source:** The Strands blog post introduces Strands Decider 2B, a 2-billion-parameter open-source model that replaces a standard text-generation head with a dedicated pointer head to enable fast, typed binary decisions (called 'noul' questions) for use in agent intervention pipelines; the source claims this makes decisions cheap enough to gate every tool call in a path where a full LLM call would be too costly.

**HN discussion:** HN commenters largely engaged with practical deployment and API design questions rather than the model's accuracy claims; one commenter raised the importance of offloading such micromodels to an NPU for better performance and lower power consumption, and another questioned the meaning of the 'noul' binary-choice API term and whether it originates from Jev's API.

### [Mistral Large 4](https://news.ycombinator.com/item?id=49977979)

- **HN engagement:** 1827 points, 1091 comments
- **Primary topic:** Mistral Large 4 open-weight multimodal LLM release
- **Evidence basis:** source-and-discussion
- **External page:** success
- **Source:** https://mistral.ai/news/mistral-large-4/\

ML4 offers a high-capability open-weight model that can be self-deployed, which is especially relevant for cybersecurity and regulated-industry use cases where closed-model refusals or loss of API access mid-incident are operational risks. Its European training and inference infrastructure also directly addresses AI sovereignty requirements for organizations under European law.

**Linked source:** Mistral Large 4 (nicknamed 'le Chonk') is a 1-trillion-parameter natively multimodal Mixture-of-Experts model with 49 billion active parameters, trained from scratch on 3,800 NVIDIA Grace Blackwell GPUs in Mistral's own European datacenters, priced at $1.36/M input tokens and $4.18/M output tokens. The source claims state-of-the-art open-weight performance in cybersecurity, agentic coding, and multimodal understanding, with weights to be released by end of month.

**HN discussion:** HN commenters debated the significance of training a frontier-competitive model on only 3,800 GPUs versus the massive US datacenter buildouts, and several assessed its practical utility for specific verticals like data analytics and cybersecurity. One commenter noted the reasoning mode toggle ('none' vs. 'high') had surprisingly little observable effect on output quality or token count.
